Hover Actions for SPL

v · runs on *.splunkcloud.com

What this extension does

Adds hover actions and copy shortcuts to Splunk Web. Everything runs against your existing Splunk session — same-origin REST reads, no external hosts, no data stored outside this browser.

  • Macro hovers — hover a `macro` in the search bar to see its full definition and jump to the definition page.
  • Lookup hovers — hover a lookup file or definition to see the owning app, fields, sample data, and edit links.
  • Lookup clause builder — on | lookup hovers, edit match fields, aliases, and OUTPUT selection, then apply the rewritten clause back into the search.
  • Live preview — type a value against a match field to preview the row that lookup would return.
  • Copy icons — one-click copy of field names and values across results tables and dialogs (full list below).

Features saved ✓

Where copy icons appear

  • Statistics tab and dashboard table headers (copies the field name)
  • Events tab, View: Table column headers, including _time (field name)
  • Field info dialog title (field name)
  • Field info dialog values list (copies the raw value, even when the display is truncated)
  • Field chips in lookup hover popups (field name)
Copied values are raw data from your events and lookups and can include sensitive information (account numbers, personal identifiers). The clipboard is yours — treat pastes accordingly.
Settings sync with your Chrome profile and apply immediately to open Splunk tabs.
