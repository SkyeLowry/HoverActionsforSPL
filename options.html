Splunk domains

The extension has no access to any website until you add your Splunk Web domain here. Adding one asks Chrome for permission for that domain only.

Have several stacks? Add *.splunkcloud.com once instead of each host — a leading *. covers every subdomain, so vancity.splunkcloud.com and es.vancity.splunkcloud.com are both included. Chrome will ask you to allow all sites on that domain.

    Works with Splunk Cloud and self-hosted Splunk Web domains. Reload any open Splunk tabs after adding.

    How it works

    Everything runs against your existing Splunk session — same-origin REST reads, no external hosts, nothing stored outside this browser. The four groups below are the whole extension; each setting applies to open tabs immediately.

    Only one feature ever dispatches a search (Sample data & live preview, in Lookup tools). Everything else either reads configuration or reads the page you are already looking at.

    1 · Search bar

    Hover any of these in the search box to see what it is actually doing, without leaving the page.

    2 · Lookup tools

    The largest capability here. Hovering a lookup does more than identify it: on a | lookup clause you get a clause builder that edits the clause and writes it back to your search.

    • Clause builder — change match fields, rename with AS, tick and untick OUTPUT fields, switch OUTPUT/OUTPUTNEW, then Apply to search to rewrite the clause in place.
    • Sample explorer — on inputlookup and outputlookup, the lookup's fields alongside a real row from the file.
    • Live preview — type a value against a match field to see the row that lookup would actually return, before you commit to the clause.
    • Overwrite guard — | outputlookup on a file that already exists warns you, with its current row count and contents. On a new name it simply confirms the file will be created.
    • Identification — owning app, whether a definition is CSV- or KV-backed, and edit links for both the definition and its backing file.

    3 · Copying fields and values

    Getting a field name or a value out of Splunk Web normally means selecting text precisely. These turn the things you already click into copy targets.

    Copied values are raw data from your events and lookups and can include sensitive information (account numbers, personal identifiers). The clipboard is yours — treat pastes accordingly.

    4 · Copying whole tables

    For when the answer is the table itself rather than one value in it.
